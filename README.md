# ต้นทุนรถของคุณ

เว็บแอปสำหรับประเมิน Total Cost of Ownership (TCO) ของรถในประเทศไทย เปรียบเทียบรถปัจจุบันกับรถใหม่ หรือประเมินรถใหม่สำหรับผู้ที่ยังไม่มีรถ

![Car TCO planner](public/car-hero.jpg)

## ทำอะไรได้บ้าง

- คำนวณต้นทุนรวมและต้นทุนเฉลี่ยต่อเดือนตามระยะถือครองที่เลือก
- คิดดอกเบี้ยแบบ Flat Rate, เงินดาวน์, ค่างวด และมูลค่าขายต่อ
- รวมต้นทุนพลังงาน, ประกัน, ภาษี, บำรุงรักษา, ยาง, แบตเตอรี่, ที่จอด, ทางด่วน และค่าใช้จ่ายเพิ่มเติม
- เปรียบเทียบต้นทุนรถปัจจุบันกับรถใหม่ พร้อมเงินสดวันเปลี่ยนรถและจุดคุ้มทุน
- เลือก “ไม่มีรถ” เพื่อดูภาระของรถใหม่โดยไม่ต้องกรอกข้อมูลรถเดิม
- ตรวจ 20/4/10 และตั้งเพดานภาระค่าเดินทางส่วนตัวได้ตั้งแต่ 10–100% ของรายได้
- แสดงกราฟ ตารางรายละเอียด และเก็บข้อมูลที่กรอกไว้ในเบราว์เซอร์เครื่องนั้น

## เริ่มใช้งาน

ต้องมี Node.js 20 หรือใหม่กว่า

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal โดยปกติคือ [http://localhost:5173](http://localhost:5173)

สร้าง production build:

```bash
npm run build
```

## วิธีใช้แบบเร็ว

1. กรอกรายได้ ระยะถือครอง ระยะทางต่อเดือน และเพดานภาระที่ยอมรับได้
2. ใน “รถปัจจุบัน” ให้กรอกมูลค่าขายต่อและต้นทุนหลัก หรือเลือก “ไม่มีรถ”
3. ใน “รถใหม่” ให้กรอกราคารถ เงินดาวน์ ดอกเบี้ย Flat Rate ระยะผ่อน มูลค่าขายต่อ และค่าใช้รถหลัก
4. เปิด “ค่าใช้จ่ายอื่น ๆ” เมื่อมีรายการ เช่น ภาษี พ.ร.บ. ค่าที่จอด หรือยาง
5. ดูต้นทุนรวม ภาระเงินสดต่อเดือน และผลผ่าน/ไม่ผ่านในส่วนผลลัพธ์

## หลักการคำนวณ

- ดอกเบี้ย Flat Rate = เงินต้นหลังหักดาวน์ × อัตราดอกเบี้ยต่อปี × จำนวนปีที่ผ่อน
- TCO = มูลค่ารถ + ดอกเบี้ย + ค่าธรรมเนียม + ค่าใช้รถตลอดระยะถือครอง − มูลค่าขายต่อ
- ภาระเงินสดระหว่างผ่อน = ค่างวด + ค่าใช้รถเฉลี่ยต่อเดือน
- ผล “คุ้มกว่า” เปรียบเทียบด้านการเงินเท่านั้น ไม่ได้ประเมินความปลอดภัย ความสะดวก หรือความชอบส่วนบุคคล

ผลลัพธ์เป็นเพียงประมาณการจากข้อมูลที่กรอก ไม่ใช่คำแนะนำทางการเงินหรือการอนุมัติสินเชื่อ
